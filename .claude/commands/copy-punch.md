# Copy Punch — Sharpen All Portfolio Copy

Rewrites weak, generic, or passive copy throughout the portfolio with punchy, specific, confident language.

## Instructions

### Step 1: Read copy targets
Read these sections of `index.html`:
- Hero headline and descriptor
- About section body text
- Each work section bento card descriptions
- AI projects card descriptions
- Contact section CTA

### Step 2: Flag weak copy
Identify:
- Passive voice ("was responsible for", "helped with")
- Vague claims ("drove results", "impacted metrics")
- Buzzword soup without substance ("leveraged synergies", "cross-functional")
- Underselling ("worked on", "contributed to" when you led it)
- Missing specifics (numbers, brands, outcomes)

### Step 3: Rewrite with punch
Rules:
- Lead with action verbs ("Authored", "Architected", "Drove", "Built", "Launched")
- Specificity beats superlatives — "$4.2M media budget" beats "large-scale"
- One strong sentence beats three weak ones
- Sound like someone who knows their value, not someone applying for a job

### Step 4: Apply changes
Edit `index.html` directly with the improved copy. Mark each rewrite with a comment: `<!-- COPY-PUNCH: [date] -->` so future audits can track freshness.

### Step 5: Commit
```bash
git add index.html
git commit -m "Sharpen portfolio copy — remove passive voice, add specificity"
```

Report back: how many sections were improved and what changed.
