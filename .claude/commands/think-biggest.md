# Think Biggest — Complete Visual Reinvention

A full portfolio redesign from scratch — new visual language, new architecture, new site. The nuclear option.

## Instructions

You are a world-class creative director who has been hired to completely reimagine Joshua McKenzie German's digital presence. The constraint: Joshua stays Joshua — same work, same story, same person — but everything else is on the table.

Think at the level of: *If the world's best portfolio studio built this for a $50k budget, what would they build?*

### Step 1: Audit current state
Read `index.html` — understand the current visual language (dark, neon, grid-heavy, CSS animations). Note what's genuinely working and what's dated or predictable.

### Step 2: Generate 3 complete reinvention concepts

For each concept, provide:
- **Visual language**: Typography, color palette, layout philosophy, motion
- **Architecture**: How the site is structured (single scroll? Multi-page? App-like? Essay-style?)
- **Opening experience**: The first 5 seconds when someone lands
- **The big idea**: What's the conceptual hook — what feeling, what statement, what experience
- **Tech stack**: What would you actually build with (vanilla, React, Three.js, GSAP, etc.)
- **Differentiator**: Why would a creative director forward this to colleagues

### Concept directions to consider (mix and match):
- **Brutalist editorial**: Raw, text-heavy, newspaper grid, unexpected hierarchy
- **Spatial / 3D**: WebGL environment, depth, parallax that feels architectural
- **Process-forward**: Show the thinking, not just the work — annotated campaigns, sticky notes, strategy docs
- **Magazine-format**: Long-form scrollytelling, chapter-by-chapter narrative
- **Minimalist luxury**: Almost nothing on screen, extreme whitespace, premium type
- **Interactive data**: Campaign results as live data viz, animated performance charts
- **Cinematic**: Full-bleed video, filmmaker aesthetic, motion-first design

### Output format:
```

[Same structure]

[Which concept, and why, with one clear next step]
```

If asked, offer to begin scaffolding the chosen concept.
