# Mood Board — Generate Visual Direction for a Campaign or Project

Creates a creative mood board with references, color story, and visual direction for any project.

## Usage
`/mood-board [project]` — e.g., `/mood-board Nike running campaign` or `/mood-board portfolio redesign`

## Instructions

### Step 1: Understand the project
If project not specified in the command, ask:
- What brand / project?
- What emotion or feeling should the work evoke?
- Who's the audience (give me one person, vividly described)?
- Any reference points you already love?

### Step 2: Generate the mood board in text

```
## MOOD BOARD — [Project Name] — [date]

### The Feeling
[One sentence: the emotion this creative should generate]

### Color Story
Primary: [hex] — [name] — [what it says emotionally]
Secondary: [hex] — [name] — [what it adds]
Accent: [hex] — [name] — [when to use it]
Avoid: [colors that would undermine the feeling]

### Typography Direction
Headline: [typeface style — e.g., "Wide grotesque, bold, lots of tracking"]
Body: [typeface style]
Accent: [typeface style — e.g., "Italic serif for pull quotes"]

### Photography Style
[Describe light quality, subject distance, lens feel, color grade, grain, etc.]

### Motion / Animation
[If applicable: speed, easing, style]

### Reference Universe
Film: [2-3 films with visual reference quality]
Photography: [2-3 photographers or photo series]
Brands that nail this vibe: [2-3 brands]
Anti-references (what NOT to do): [1-2 examples]

### The One Image
If this campaign were one single image, describe it:
[Vivid description]
```

### Step 3: Offer next steps
- "Turn this into a creative brief with `/brief-me`?"
- "Write POV copy for this campaign direction with `/write-pov`?"
